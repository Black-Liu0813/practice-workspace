# Skills Index — 技能库索引

> Agent 完成任务积累的可复用技能。
> `skills/active/` = 已审核入库 | `skills/drafts/` = 待审草稿

## 如何使用

1. **Agent 检索**: 收到任务时，扫描 `skills/active/` 按标签匹配相关 skill
2. **Agent 沉淀**: 完成复杂任务后，将可复用模式写入 `skills/drafts/`
3. **人审核**: review draft，修改后移入 `skills/active/`
4. **创建新 skill**: 从 `skills/TEMPLATE.md` 复制
